🚀 QUICK START (COPY & PASTE)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Open Command Prompt
  cd d:\BBMS

STEP 2: Create & Activate Virtual Environment
  python -m venv venv
  venv\Scripts\activate

STEP 3: Install Dependencies
  pip install -r requirements.txt

STEP 4: Create Database (in new terminal)
  mysql -u root -p
  source d:\BBMS\schema.sql;
  exit

STEP 5: Update MySQL Password in app.py (line 20)
  app.config['MYSQL_PASSWORD'] = 'your_password'

STEP 6: Run Application
  python app.py

STEP 7: Open Browser
  http://localhost:5000

🎯 CORE WORKFLOWS
═══════════════════════════════════════════════════════════════════════════════

WORKFLOW 1: RECORD A BLOOD DONATION
  Donor Records Donation
       ↓
  Trigger Fires Automatically
       ├─ Inventory increases ✓
       └─ Last donation date updates ✓

WORKFLOW 2: REQUEST BLOOD (AUTOMATED)
  Hospital Makes Request
       ↓
  Stored Procedure Checks Inventory
       ├─ Sufficient? → Approve + Deduct ✓
       └─ Insufficient? → Reject ✓

WORKFLOW 3: MANUAL REQUEST MANAGEMENT
  Admin Reviews Pending Requests
       ├─ Click ✓ to Approve
       │  └─ Inventory automatically decreases
       └─ Click ✗ to Reject
